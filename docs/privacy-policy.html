AI Selection Assistant Privacy Policy

Effective date: July 5, 2026

English Version

AI Selection Assistant is a Chrome extension that lets users select text on any webpage or open an AI chat box from the context menu. We do not operate our own backend service or user account system. Most data processing happens in the user's browser or is sent directly to the API provider configured by the user.

Key point: We do not upload data to our own servers. Data only flows between the user's browser, Chrome sync storage, and the third-party API provider selected by the user.

Data We Process

  • Local settings such as Quick Prompts, API Base URL, API Key, and model selection stored in chrome.storage.sync.
  • User input, selected text, and page context used to generate responses.
  • Page content, images, or form information when the user explicitly activates the extension.

How We Use Data

  • To display and manage the extension UI.
  • To save user settings and quick prompts.
  • To send the selected context to the user's chosen OpenAI-compatible API provider.
  • To temporarily read, interact with, or fill in the current webpage after user activation.

Permission Reasons

  • storage: Store quick prompts, API Base URL, and API Key.
  • activeTab: Temporarily access the current page after the user clicks the extension.
  • contextMenus: Open the chat box even when no text is selected.
  • Website access: Read page content, extract information, fill forms, and operate page elements.

Data Sharing

We send the user's prompts, selected content, and necessary page context to the third-party API provider configured by the user for AI generation. That provider's privacy practices are governed by its own policies and terms.

Retention and Deletion

Settings are stored in chrome.storage.sync and may sync across the user's Chrome devices. Conversation content generally stays in the browser during runtime and is not uploaded to our own servers. Users can clear local data from the extension settings or remove the extension to stop further processing.

中文版本

1. 概述

AI 劃詞助手是一款 Chrome 擴充功能，讓使用者在任意網頁上選取文字或透過右鍵選單快速開啟 AI 對話框。此擴充功能不設置獨立伺服器，也不建立使用者帳號系統；主要資料處理都發生在使用者的瀏覽器中，或是直接傳送給使用者自行設定的 API 供應商。

重點：本擴充功能不會將資料上傳到我們自己的後端服務；資料僅會在使用者的瀏覽器、Chrome 同步儲存空間，以及使用者選定的第三方 API 供應商之間流動。

2. 我們收集或處理的資料

本機設定

API Base URL、API Key、快速預設問題、模型名稱與其他設定值會儲存在 chrome.storage.sync，以便跨裝置同步。

使用者輸入

使用者在對話框輸入的問題、選取的文字、以及頁面中擷取到的上下文內容，會用於產生回覆。

頁面內容

當使用者啟用功能時，擴充功能可能讀取目前頁面的內容、選取範圍、圖片或表單資訊，以完成對話與填入操作。

3. 資料如何使用

我們僅會將資料用於下列目的：

  • 顯示與管理擴充功能介面。
  • 儲存使用者的設定與快速預設問題。
  • 依照使用者選定的 API Base URL 與 API Key，呼叫第三方 AI 服務以取得回覆。
  • 在使用者觸發後，對目前網頁進行暫時性的讀取、互動或填入操作。

4. 權限與用途說明

為了讓 Chrome Web Store 與使用者清楚了解權限用途，以下是本擴充功能所申請權限的理由：

storage

儲存快速預設問題、API Base URL、API Key。

activeTab

允許擴充功能在使用者點擊後，暫時存取目前所在頁面。

contextMenus

可在不劃詞時開啟對話框。

網站存取權限

擴充功能需要讀取頁面內容、擷取資訊、填入表單、操作頁面元素等。

5. 與第三方服務的資料分享

本擴充功能會將使用者輸入、選取內容、以及必要的頁面上下文傳送到使用者自行設定的第三方 API 供應商，以執行 AI 推論與回應生成。請注意，該第三方供應商對資料的處理方式，會依其自身隱私權政策與服務條款而定。

若使用者將 API Key 設定為第三方服務提供的金鑰，則該服務可能會依其機制記錄請求與使用資訊。

6. 資料保存與刪除

設定資料會保存在 chrome.storage.sync，並可能透過 Chrome 帳號在使用者裝置之間同步。對話內容主要存在於瀏覽器執行期間，不會上傳到我們自己的伺服器。

使用者可透過瀏覽器的擴充功能設定頁面清除本機資料，或移除擴充功能以停止後續資料處理。

7. 資料安全

我們採取最小權限原則設計擴充功能，並避免將 API Key 寫入程式碼或公開文件。使用者仍應自行保護 API Key 與帳號安全，並確認所使用的第三方 API 供應商具備適合的安全與隱私措施。

8. 兒童隱私

本擴充功能並非特別設計給 13 歲以下兒童使用。我們不會刻意蒐集兒童個人資料。

9. 政策變更

若我們未來更新隱私權政策，將在此頁面更新版本內容與生效日期。建議使用者定期檢視本頁，以了解最新說明。

10. 聯絡方式

如需詢問本隱私權政策，請透過專案頁面或 Chrome Web Store 列出的聯絡方式與我們聯繫。
